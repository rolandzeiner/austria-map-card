# Austria Map Card

A zoomable layer map of Austria for Home Assistant dashboards.

<img src="https://raw.githubusercontent.com/rolandzeiner/austria-map-card/main/screenshots/preview.webp" alt="Map of Austria with terrain, rivers, province borders and the largest towns" />

The first release is being prepared on the [`dev` branch](https://github.com/rolandzeiner/austria-map-card/tree/dev). This branch holds only the project scaffold, so a card installed from it is empty. To try the card now, install the latest pre-release: in HACS, turn on beta versions for this repository.
